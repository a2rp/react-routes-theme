# React Routes Theme

A display-only React routing and theme showcase with a searchable sidebar, deep-link pages, reusable layouts, and a large set of business interface examples.

![React Routes Theme preview](screenshot.png)

## Features

- Lazy-loaded route catalog with deep links
- Searchable and collapsible sidebar navigation
- Dark and light theme support
- Breadcrumbs, print helpers, modals, tables, forms, and dashboard screens
- Responsive fixed header with independently scrolling navigation
- Static fixtures for safe frontend exploration

## Tech stack

React, Vite, React Router, Material UI, styled-components, and React Icons.

## Run locally

``bash
npm install
npm run dev
``

## Build and deploy

``bash
npm run lint
npm run build
npm run deploy
``

Live demo: [a2rp.github.io/react-routes-theme](https://a2rp.github.io/react-routes-theme/)

Future improvements can connect the display screens to real services and shared data sources.
